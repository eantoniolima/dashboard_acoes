# dashboard_acoes
Dashboard de ações em Python com Streamlit, inspirado no tutorial do Código Quant, com créditos ao autor. Inclui ajustes de CSS nos grids, card do Ibovespa e análise de retorno e volatilidade. Desenvolvido para estudar o mercado financeiro e construir um portfólio de análises usando Pandas, NumPy, yfinance e Plotly.
